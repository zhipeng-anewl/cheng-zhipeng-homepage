# 程志鹏 · 个人主页（第一版原型）

一个可直接预览的单页个人主页，包含头像、名字与一句话介绍、个人信息展示区，以及一个本地规则版的数字分身聊天区。

## 预览方式

直接双击打开 `index.html` 即可。页面不依赖网络、构建工具或后端。

如果想用本地服务器预览：

```powershell
python -m http.server 4173 --bind 0.0.0.0
```

然后访问 `http://127.0.0.1:4173/`。

### 手机预览

`127.0.0.1` 只代表电脑本机，手机无法访问。让手机和电脑连同一个 Wi-Fi，然后：

1. 在电脑上运行 `ipconfig`，找到 WLAN 的 IPv4 地址，例如 `10.182.15.102`
2. 用手机浏览器打开 `http://10.182.15.102:4173/`
3. 如果打不开，检查 Windows 防火墙是否允许 Python 或 4173 端口通过专用网络

微信内置浏览器可能限制局域网地址，优先用手机自带的 Safari / Chrome 打开。

## 数字分身的边界

当前版本是**本地规则版**，不联网、不调用大模型、不保存对话。它只能回答 `INTENTS` 中预设过的问题；资料之外的问题会明确说不知道，不会编造经历。

后续如果想升级成真正的 AI 分身，可以保留现在的前端聊天界面，把 `getReply()` 替换成后端 API 调用，并在服务端注入个人资料与回答边界。
